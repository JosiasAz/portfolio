## Stack

- [Next.js 15](https://nextjs.org/) (App Router)
- React 19 + TypeScript
- CSS
- Canvas para estrelas, Via Láctea e meteoros
- Áudio ambiente (play sob demanda)

## Começar

Requisitos: Node.js 18+

```bash
npm install
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000).

### Scripts

| Comando | Descrição |
| --- | --- |
| `npm run dev` | Desenvolvimento |
| `npm run build` | Build de produção |
| `npm start` | Serve o build |
| `npm run lint` | ESLint |

## Estrutura

```text
src/
  app/            # layout, page, CSS global
  components/     # hero, seções, céu, nav, música
  data/           # projetos, stack, telas, links
  lib/            # lógica do canvas do céu
public/assets/    # imagens, ícones, áudio
```

Conteúdo editável em `src/data/` (projetos, ferramentas, contato).
